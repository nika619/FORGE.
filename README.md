# F.O.R.G.E.

[![CI](https://github.com/nika619/FORGE./actions/workflows/ci.yml/badge.svg)](https://github.com/nika619/FORGE./actions/workflows/ci.yml)
### Framework for Objective Routing & Gamified Execution

F.O.R.G.E. is a premium, fully interactive gamified productivity engine. Engineered with a strict "Obsidian Navigator" 3D-hybrid aesthetic, it transforms mundane task management into navigating a high-stakes tactical game lobby. Turn your biggest ambitions into actionable quests, earn XP, and level up your execution.

## 🚀 The Architecture of Immersion

### Phase 1: The Goal Forge (Landing)
The cinematic entry point into the system. Displaying an overlaid tactical HUD, users input their master objective to trigger the AI formulation sequence.

### Phase 2: The Chronicle (Dashboard)
The main operational interface. Engineered with a pure `void black` background (`#020203`), sharp tactical geometry (0-4px border radii), and intense `Neon Cyan` (`#00F0FF`) and `Deep Violet` (`#7000FF`) active state glows.

## ✨ Core Features

*   **Goal Forge Engine:** Input your objectives and let the system break them down into actionable quests.
*   **The Chronicle Dashboard:** Track your daily progress, active quests, and overall capability level.
*   **Tactical Quest Board:** Manage quests with filters, detailed expansions, and sub-task execution.
*   **AI Goal Planner:** Generate AI-driven sub-tasks and timelines based on your master objectives.
*   **Achievement Gallery:** Unlock grid-based tactical trophies as you accrue XP and finish specific quests.
*   **Profile Analytics:** Monitor your skill distribution, growth metrics, and quest history.

## 🛠️ Technology Stack

*   **Framework:** React 18 / Vite
*   **Architecture:** Feature-Sliced Design (FSD)
*   **State Management:** Zustand
*   **Styling & UI:** Vanilla CSS + Lucide React Icons
*   **Animations:** Framer Motion (Strict Easing Curves)
*   **TypeScript:** 100% Strict Type Coverage

## 📥 Getting Started

### Prerequisites
*   Node.js (v18+)
*   npm or yarn

### Installation
1.  Clone the repository.
    ```bash
    git clone https://github.com/yourusername/forge.git
    cd forge
    ```
2.  Install dependencies.
    ```bash
    npm install
    ```
3.  Start the development server.
    ```bash
    npm run dev
    ```
4.  Launch your browser and navigate to `http://localhost:5173`.

## 🎨 Design Philosophy
F.O.R.G.E. breaks away from traditional productivity soft-UI. It replaces friendly rounded corners and bright whites spaces with sharp tactical geometry, dark matter backgrounds, and intense light-emitting data visualizations. Every interaction is meant to feel purposeful, tactile, and rewarding.
